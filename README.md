## How Viator discounts actually work

Viator's own help centre describes three separate promotion types, and knowing which one you're dealing with saves a lot of frustration:

- **On-site special offers** — deals displayed on the website or app that apply automatically at checkout. No code needed.
- **Email specials tied to your location** — sent by email and applied automatically, as long as you arrive through the specific link provided.
- **Promo codes** — sent by email, typed into the promo code box at checkout.

Two details from the same source are worth holding onto. Viator's call centre and chat staff don't have access to promotional discounts, though they can usually apply a valid code you received by email to a new booking. And some promotions require you to be signed in to your Viator account, so checking out as a guest can quietly drop the discount.

The practical consequence: a Viator promo code is not a public commodity you can reliably find on a coupon aggregator. It's usually issued to a specific person or tied to a specific campaign window.

**Short-window campaign codes** — these come and go fast, and their shape is more useful than any single string. The pattern: minimum spend thresholds, a handful of weeks at most, sometimes restricted to one region or one campaign.

If you find a code with no published terms, no expiry date and no named issuer, treat it as noise until it survives checkout. More importantly — apply it *before* you start the cashback route below, because on Viator the two can conflict.

## Why most Viator coupon codes fail at checkout

The failures are rarely mysterious:

- **One code per transaction.** Viator's terms for partner promotions state only one promo code can be applied per booking. Stacking two codes isn't a thing.
- **Not combinable with other offers.** Card-partner discounts explicitly exclude combining with other promotions.
- **The app is excluded.** Both the Amex offer and ShopBack's Viator terms rule out purchases made in Viator's mobile app. Browser, every time.
- **Location and account gating.** Email specials are tied to a location and often require you to be logged in.
- **Minimum spend.** $250, $500 — the discounts are frequently aimed at bigger bookings, not a $30 walking tour.
- **Currency and country.** Offers are issued per market, so a US-only code does nothing on a Singapore or Australian booking.
